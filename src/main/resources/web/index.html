12 topics

Variables & Assignment

Core

Declare with let or assign dynamically without declaration. Reassign with arithmetic updates.

let score = 100; score = score + 25; name = "Alex"; say name; show score;

Kid-Friendly Repeat Loops

Control

Execute a block of code a set number of times without complex loop indices.

repeat 4 times { say "MiniLang is simple and fast."; }

Conditionals & Logic

Logic

Branches with if and else. Parentheses optional. Uses and, or, not, is.

let score = 85; if score >= 80 and not (score is 100) { say "Great score!"; } else { say "Keep going!"; }

Functions

Functions

Define reusable subroutines using fn or def with parameters and return values.

fn addNumbers(a, b) { return a + b; } let total = addNumbers(15, 25); print("Total: " + str(total));

Classes & OOP

OOP

Object-oriented classes with class, constructor init, methods, and this or self.

class Vector2D { init(x, y) { this.x = x; this.y = y; } magnitude() { return sqrt(this.x * this.x + this.y * this.y); } } let v = Vector2D(3, 4); print("Magnitude: " + str(v.magnitude()));

Arrays & Lists

Data

Dynamic collections indexed with arr[i]. Built-ins include push, pop, and len.

let items = [10, 20, 30]; push(items, 40); print("Length: " + str(len(items))); print("First: " + str(items[0])); print("All: " + str(items));

Dictionaries (HashMaps)

Data

Key-value mappings with { "key": val }. Inspect with has, keys, values, and len.

let user = { "name": "Ada", "score": 95 }; user["role"] = "Engineer"; print("Name: " + user["name"]); print("Keys: " + str(keys(user))); print("Has role? " + str(has(user, "role")));

Exception Handling (Try / Catch)

Safety

Safely intercept division by zero, invalid indexes, and file errors without halting execution.

try { let res = 100 / 0; } catch (err) { print("Handled error: " + err); } print("Program continues safely.");

Multi-line Raw Strings

Strings

Triple-quoted strings """ ... """ retain newlines and formatting verbatim.

let banner = """ +-----------------------------+ | MiniLang Language Workbench | +-----------------------------+ """; print(banner);

File I/O Built-ins

System

Read and write files directly: writeFile, readFile, appendFile, fileExists, deleteFile.

writeFile("demo.txt", "Hello from MiniLang!\n"); appendFile("demo.txt", "Appended log line.\n"); print(readFile("demo.txt")); deleteFile("demo.txt");

Algorithms & Statistics

Algorithms

Fast standard library routines: sort, mean, median, sum, reverse, range, binarySearch.

let nums = [42, 17, 88, 3, 99, 12]; print("Original: " + str(nums)); print("Sorted: " + str(sort(nums))); print("Mean: " + str(mean(nums))); print("Median: " + str(median(nums)));

Mathematical Built-ins

Math

Built-in numeric functions: sqrt, pow, abs, round, floor, ceil, sin, cos, random.

print("Square root 256: " + str(sqrt(256))); print("2 to power 10: " + str(pow(2, 10))); print("Round 4.75: " + str(round(4.75)));
