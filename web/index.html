Hello World & Console Output

Basics

Print values to standard output. say and show are kid-friendly aliases for print.

say "Hello, World!"; show 42; print("MiniLang is live!");

Variables & Assignment

Basics

Declare with let or assign dynamically without keywords. Variables support dynamic typing.

let score = 100; score = score + 25; name = "Alex"; say name; show score;

Data Types & Type Inspection

Basics

Inspect runtime types using type(val): integer, float, string, boolean, array, map, null.

print(type(42)); print(type(3.14)); print(type("text")); print(type([1, 2])); print(type({ "a": 1 }));

Arithmetic Operators

Basics

Standard mathematical operations: +, -, *, /, % with standard precedence.

let a = 20 + 5; let b = 100 / 4; let c = 17 % 5; print("20 + 5 = " + str(a)); print("17 % 5 = " + str(c));

Strings & String Multiplication

Basics

Concatenate strings with + and repeat strings with multiplication *.

let greeting = "Hello " + "World!"; let cheer = ("Hip " * 2) + "Hurray!"; print(greeting); print(cheer);

Conditionals & English Logic

Control

Branches with if and else. Parentheses optional. Uses and, or, not, is.

let score = 85; if score >= 80 and not (score is 100) { say "Great score!"; } else { say "Keep going!"; }

Kid-Friendly Repeat Loops

Control

Execute code blocks $N$ times directly without complex counter variables or loop boilerplate.

let step = 1; repeat 3 times { say "Loop iteration #" + str(step); step = step + 1; }

While Loops (Break & Continue)

Control

Loops while condition holds true. Supports break to exit early and continue to jump.

let i = 0; while i < 8 { i = i + 1; if i == 3 continue; if i == 6 break; print("i = " + str(i)); }

For-In Loops

Control

Iterate sequentially over array items, range sequences, or characters in a string.

for fruit in ["Apple", "Berry", "Cherry"] { say fruit; } for x in range(3) { print("Range step: " + str(x)); }

Functions & Parameters

Functions

Define reusable subroutines using fn or def with parameters and return values.

fn addNumbers(a, b) { return a + b; } let total = addNumbers(15, 25); print("Total: " + str(total));

Recursive Functions

Functions

Functions calling themselves, protected by a VM recursion call-stack limit (1000 frames).

fn factorial(n) { if n <= 1 return 1; return n * factorial(n - 1); } print("factorial(5) = " + str(factorial(5)));

Arrays & Lists

Data

Dynamic collections indexed with arr[i]. Built-ins include push, pop, and len.

let items = [10, 20, 30]; push(items, 40); let last = pop(items); print("Length: " + str(len(items))); print("First: " + str(items[0])); print("All: " + str(items));

Dictionaries (HashMaps)

Data

Key-value mappings with { "key": val }. Inspect with has, keys, values, and len.

let user = { "name": "Ada", "score": 95 }; user["role"] = "Engineer"; print("Name: " + user["name"]); print("Keys: " + str(keys(user))); print("Has role? " + str(has(user, "role")));

Classes & Constructors

OOP

Define custom object types with class and the init(...) constructor method.

class Player { init(name, level) { this.name = name; this.level = level; } } let p = Player("Nova", 10); print(p.name + " level: " + str(p.level));

Class Methods (this / self)

OOP

Methods bound to instances. Both this and self work seamlessly as receiver references.

class Vector2D { init(x, y) { this.x = x; this.y = y; } magnitude() { return sqrt(this.x * this.x + this.y * this.y); } } let v = Vector2D(3.0, 4.0); print("Magnitude: " + str(v.magnitude()));

Exception Handling (Try / Catch)

Safety

Catch runtime errors (divide by zero, bad indices, missing files) and recover without crashing.

try { let res = 100 / 0; } catch (err) { print("Caught error: " + err); } print("System remains stable.");

Multi-line Raw Strings

Strings

Triple-quoted strings """ ... """ preserve line breaks, indentation, and quotes verbatim.

let banner = """ +-----------------------------+ | MiniLang Language Workbench | +-----------------------------+ """; print(banner);

File I/O Built-ins

System

Disk file management: writeFile, readFile, appendFile, fileExists, deleteFile.

writeFile("demo.txt", "Hello from MiniLang!\n"); appendFile("demo.txt", "Appended log line.\n"); print(readFile("demo.txt")); deleteFile("demo.txt");

Algorithms & Statistics

Algorithms

Fast standard routines: sort, mean, median, sum, reverse, range, binarySearch.

let nums = [42, 17, 88, 3, 99, 12]; print("Original: " + str(nums)); print("Sorted: " + str(sort(nums))); print("Mean: " + str(mean(nums))); print("Median: " + str(median(nums)));

Mathematical Built-ins

Math

Built-in numeric functions: sqrt, pow, abs, round, floor, ceil, sin, cos, random.

print("Square root 256: " + str(sqrt(256))); print("2 to power 10: " + str(pow(2, 10))); print("Round 4.75: " + str(round(4.75))); print("Random in [0,1): " + str(random()));
